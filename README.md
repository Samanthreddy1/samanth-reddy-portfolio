## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/samanth-reddy-portfolio.git
```

**2. Navigate to the project folder**

```bash
cd samanth-reddy-portfolio
```

**3. Open the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No backend server or package installation is required.

## Deploying with GitHub Pages

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder.
5. Click **Save**.

Once deployment completes, the website should be available at:

`https://Samanthreddy1.github.io/samanth-reddy-portfolio/`

Replace `Samanthreddy1` with your actual GitHub username.
